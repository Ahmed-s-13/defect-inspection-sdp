# 2. Healing experiment: generate "no damage" patches by inpainting the defect away

**Status: experiment in progress (steps 1–4 done, steps 5–6 not built yet).**

Idea: none of our datasets has a "no damage" class. Instead of finding clean images,
take a defect crop (we know its box), remove the defect with an inpainting network,
and use the "healed" patch as a non-defective example for a two-stage classifier
(Stage 1: defect yes/no; Stage 2: which defect, using the main ResNet-18). Healing
runs offline only; the helmet would never heal images. The full spec is in
[`docs/TASK_SPEC.md`](docs/TASK_SPEC.md).

## What it reuses (no copies)

This folder has no copy of code from other folders. It imports it:

| from | what | used for |
|---|---|---|
| `../1_main_model_resnet18/klshift/common.py` | crop size, transforms, ResNet-18 builder, dataset class | every step |
| `../1_main_model_resnet18/prepare.py` | YOLO label parser | step 1 |
| `../1_main_model_resnet18/shift.py` | KL estimators, group halves, ellipses | step 4 |
| `../1_main_model_resnet18/data/work/` | D1 crops, the D1 split, `model_best.pt` (the main model) | every step |
| `../1_main_model_resnet18/results/embeddings.npz` | D1 embeddings, `in_d1` flags | step 4 |
| `../3_teacher_student_msrd/msrd_anomaly.py` | the MSRD teacher–student model, unchanged | steps 2–4 |

`hcommon.py` sets up these paths in one place. So this folder only runs when
`1_main_model_resnet18/data/` is present (see that folder's README).

## Files, in run order

| step | script | what it does | result |
|---|---|---|---|
| 1 | `clean_patches.py` | samples real clean patches from D1 regions that touch no box, sized like the defect crops | [`step1_clean_stats.md`](results/healing/step1_clean_stats.md) |
| 2 | `ts.py` | trains the MSRD teacher–student on D1-train clean patches; this is the **baseline** healing must beat; filters the clean set | [`step2_ts_baseline.md`](results/healing/step2_ts_baseline.md) |
| 3 | `healer.py --train`, then `healer.py --heal` | small U-Net inpainting healer; writes healed crops and control crops | [`step3_healer.md`](results/healing/step3_healer.md) |
| 4 | `checks.py`, `probe_reencode.py` | did healing work? teacher–student scores, KL, PCA, and the **artifact probe** | [`step4_checks.md`](results/healing/step4_checks.md) |
| – | `hcommon.py` | shared paths and data loaders for this folder | |
| – | `bincls.py` | stock ResNet-18 binary classifier (artifact probe, later Stage 1) | |

Run every script from this folder, e.g. `python ts.py --help`.
[`results/healing/00_codebases.md`](results/healing/00_codebases.md) summarises the two
codebases this builds on.

## Results so far (D1-test)

- Teacher–student baseline: image AUROC 0.621, clean vs defect.
- **Artifact probe: a fine-tuned ResNet-18 tells healed patches from real clean ones with AUROC 1.000.**
  The inpainting leaves a fingerprint. A Stage 1 trained on healed patches would learn
  "inpainted = clean". Re-saving the JPEG alone gives 0.502, so the cue is the inpainted pixels.
- Details and figures: [`results/healing/step4_checks.md`](results/healing/step4_checks.md).
