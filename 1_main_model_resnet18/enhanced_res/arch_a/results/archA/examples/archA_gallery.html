Architecture A in pictures

enhanced_res on d1_grouped, unchanged weights. Pipeline: quality gate (α 0.1) → unfamiliar-input gate (α 0.1) → temperature (T = 1.342) → conformal set (LAC, α 0.10). Thresholds come from the calibration half (1,838 crops, 88 photo families); everything below is measured on the other half (2,417 crops, 87 families), which nothing was fitted on. Example crops are random (seeded), one per photo family where possible.

False reject = a good, normal crop that a stage stops or doubts (costs inspector time). False accept = something a stage should have stopped but let through (a bad image, a non-aircraft image, or a wrong single answer shown with no warning).

1. Unfamiliar-input gate · 2. Temperature · 3. CP coverage · 4. False accept / reject everywhere

1. Unfamiliar-input (OOD) gate: "CAN'T ASSESS: re-aim"

Each crop's 768 model features are compared with the 20,179 training crops; the score is how far it is from its 5 nearest neighbours. Far away = unfamiliar. The cut-off is set on normal calibration crops so that about 10% of normal photo families are flagged.

Normal crops flagged (false reject): 5.7% per crop, 9.7% per family · off-target patches caught: 77.2% (false accept 22.8%; with the quality gate too: caught 82.5%) · AUROC off-target vs normal: 0.939 (energy 0.710, max probability 0.699).

2. Temperature scaling: making the % honest

One number, T = 1.342, fitted on val: every probability is raised to the power 1/T and renormalised. It softens the model's overconfidence. The top class never changes, so accuracy stays 79.1%. Bars below the dashed line = the model claims more than it delivers. White numbers = crops in each bin.

Mean stated confidence 89.4% → 80.8% against 79.1% actually right · ECE 0.105 → 0.035 · same top class on 100.0% of crops.

3. Conformal prediction: does the set hold the true class?

The set is every class whose (temperature-scaled) probability is at least 1 − q, with q chosen on the calibration half so the true class is inside about 90% of the time (α 0.10).
